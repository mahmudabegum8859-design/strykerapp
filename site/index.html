Setup modes

One app, three engines

Choose at first launch — switch the experience to your device, your access level and your comfort zone.

Root required

Rooted Mode

Mounts a real Debian trixie chroot on-device. Full performance, direct hardware access, apt package manager.

  • Debian trixie rootfs, arm64
  • Native speed — no emulation
  • apt install any tool
  • Direct adapter / hardware access
No root needed

Rootless Mode

Boots a full Linux VM under QEMU — zero root. Pick the guest architecture on the setup screen: arm64 (tested), armhf, i386 or amd64.

  • QEMU VM, user-mode networking
  • 4 guest architectures
  • USB WiFi adapter passthrough
  • 9p capture share to /sdcard
Nothing installed

Tour Mode

Walk through every feature of the app with nothing downloaded, extracted or executed — no root, no chroot, no VM.

  • Explore every screen & button
  • Zero installs, zero payloads
  • Safe on any device
  • Perfect first-run experience
Architecture support

Built for every phone

Payloads for each architecture live on the core-files release. Rooted mode mounts a Debian chroot matching the device ABI; Rootless mode boots a QEMU guest of the chosen architecture. arm64 is fully tested; armhf / i386 / amd64 are boot-verified under QEMU but not yet device-tested.

FAQ

Questions, answered

Does OPXdemon need root?
No. Rooted Mode needs root for the chroot, but Rootless Mode boots a complete QEMU VM without any root, and Tour Mode installs nothing at all.
Which devices are supported?
Any arm64 Android device with Android 7.0+ (API 24). The rootless engine can additionally run armhf, i386 and amd64 guests — those payloads are boot-verified under QEMU but not yet device-tested.
How do updates work?
The app fetches opxdemon_manifest.json from the repository, verifies the SHA-256 of downloads, and prompts for new versions. This page does the same — the download button and changelog are auto-detected from the GitHub releases.
Where do the payloads come from?
All rooted and rootless payloads (kernels, initramfs, rootfs images, QEMU emulators, Debian chroots) are published on the core-files release of this repository — 26 files across four architectures.
Is this legal to use?
OPXdemon is an authorized-security-testing tool. Only use it on networks and devices you own or have explicit permission to test, and follow all applicable laws.
